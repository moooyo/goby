## Mechanism and bounded scope

The retained Beverly sources share scene actions under different credit
overlays, framing and photometric conditions. The preceding global descriptor
and temporal-difference experiments did not justify changing the detector.
Investigate one fixed local representation before any product adoption.

Extract full-frame 96-by-96 grayscale observations from the first 120 seconds
at 100 ms, with at most 1,200 frames per source. Reuse B1/B2/B7, NASA
N388/N389/N390, One Step Beyond O1/O2/O3 and Hubble H114/H116/H118 originals.
The Hubble controls specifically test whether overlay tolerance swallows
protected episode-title content. Preserve the complete
source PTS audit, source/tool identities, exact selected PTS and frame hashes.
Only complete extraction manifests authorize consumption of compressed rasters.
No new source media is acquired during mechanism diagnosis.

The private representation uses 25 fixed local patches, deterministic binary
intensity comparisons and reliable-bit masks. The experiment protocol fixes
geometry, distance, contrast, dynamic, periodicity and work limits before
source evaluation. Geometry is fixed for a whole source, with complete sampling
support and no boundary clamping. A group's entire window retains one spatially
distributed patch set, including central foreground regions. No frame can
replace a failing patch with a different successful patch.

Every patch's coverage uses the intersection of all clique edges at the same
anchor sample and the same source-frame mapping. Each source mapping has
one-to-one ownership and retains missing/conflicting frames in its denominator.
Dynamic events use the reliable-bit intersection across both times and every
source, and count only changes whose direction agrees across all sources.
All clique edges must confirm each event at one anchor time. Different edges
cannot borrow evidence from different bits or frames. Three independent sources,
an eight-second minimum and protected-content semantics remain required.

Same-action source points are bounded correspondence probes, not necessary
conditions for the entire prefix: valid coverage could exclude those samples.
They may not choose production geometry, windows or source-specific parameters. Full
prefix discovery must use the declared search. Exceeding a bound returns no
partial successful result. All failed attempts and controls remain available.

After the first complete development attempt, one explicit nomination revision
is allowed and recorded separately: remove the requirement that four patches
move at the same coarse nomination sample. That requirement is stronger than
the final rule, which permits the fixed dynamic patches to have different
event times. Preserve the descriptor, geometry ranking, final group gates and
budgets. Repeat all four development cohorts once; do not describe the repeat
as unseen evidence or assume recall/false-positive monotonicity.

If that fixed-grid route still provides no full group, perform one separate
keypoint correspondence probe using the same audited 96-by-96 frames. Freeze
one ORB, mutual-ratio Hamming matching and affine-estimation configuration
before execution. Use the three existing source-action points without temporal
neighbor selection and fixed NASA/OSB control points. Record all match counts,
spatial distributions, residuals and three-way point cycles. These are point
correspondences, not interval, motion or intro-recognition evidence. Official
software wheels may be installed only in an owned remote temporary directory,
with versions/hashes retained and no production dependency changes.

## Adoption and evaluation

A viable mechanism must pass full-clique and control checks before integration.
The new descriptor has a different measurement distribution; its numerical
thresholds are not equivalent to existing luminance thresholds. Adoption must
bind a new evidence policy and account for actual source raster storage,
extraction profile, work/memory limits and historical cache/result readers.
Neutral binary descriptors cannot recreate raw frames for later geometry search.

All 33 previously evaluated cases remain development material. A product
candidate requires a newly selected and independently source-labeled episode
set, frozen before first evaluation. Preserve failed first results and keep
repeated observations out of the independent denominator. A private prototype
or a completed investigation is not itself a production recall improvement.
