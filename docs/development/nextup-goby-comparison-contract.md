scope. Freeze a manifest that binds:

- The selected Goby source manifest, publication checkpoint, executable bytes,
  actual PID/start time/invocation, endpoint and isolation identity. Source55
  and the architecture-audit build are distinct artifacts; choose and verify
  the intended bytes explicitly.
- The currently observed schema, complete migration history, database and
  relation ownership, recovery generation and existing coordination locks.
  A historical source55/schema28 receipt is not a current process observation.

  three-episode series. Bind six approved 600-second synthetic media files,
  their hashes, catalog relationships and public full-detail observations.
- An explicit semantic mapping for P/Q, LA/LB, A/B, seasons and A1-A3/B1-B3.
  Keep library-management, policy-folder, view, source-root and item identities
  separate. Map actual returned identifiers; never borrow reference numeric IDs.

  configurations and preferences, plus complete owned-database assertions.
- Exact planned requests, cleanup routes, normal budget and reserved cleanup
  budget. Preparation, protocol comparison and any later browser work have
  separate allowances. The API phase may use at most 300 requests with 80
  reserved for reconciliation and cleanup unless a new reviewed plan states

## Execution and interpretation

First independently review the frozen reference ledger and enumerate the exact
SeriesId, global, detail and cleanup requests to compare. Preserve order and
primitive types. Normalize only explicitly mapped target identifiers and
intrinsically variable values; retain field absence, errors and ordered result
positions as observed facts.

Establish equivalent owned histories through Goby's public
PlaybackInfo/Started/Progress/Stopped lifecycle. Read every resulting full item
detail and use read-only assertions against Goby's own database to verify the
durable effect. Do not inject history through SQL or infer completion from
acknowledgement status alone. Use distinguishable real persisted activity times;
reference timestamps are evidence, not values to write into the candidate.

Record observed matches and differences per request. A global payload difference
in these reproduced samples is an observed difference with an unresolved general
selection contract. It does not authorize an unconditional empty selector.
Any product change must name the exact evidenced rule it implements and retain
authorization, recursive scope and batched projection guarantees. Existing
Goby-only assertions may remain useful regressions, with their policy status
explicitly recorded.

If a demonstrated product change is needed, freeze the revised source and run
the relevant Store/HTTP tests remotely, followed by the required verification
for that implementation checkpoint. Verify deployed behavior against those exact
bytes. Passing tests establish their covered Goby behavior, not the missing
positive reference or original-client gates.

Journal state-changing intent before dispatch. On an uncertain response, retain
responsibility and reconcile only the known owned state; do not blindly repeat
playback reports or restoration writes. Stop each owned playback session and
restore only changes made by this new run to its measured zero baseline. Verify
all affected episode details and complete scoped state. Each recorder logout
requires a rejection check with that exact token. New devices, accounts and
legitimate audit/authentication history need an explicit retained disposition.

original-client playback/refresh, primary upgrade or complete M2-M6 acceptance.
